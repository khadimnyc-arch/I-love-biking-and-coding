# I Love Biking and Coding

Just a perfect blend of two worlds I love.
## Features

* **Custom Vector Graphics:** Renders a detailed bicycle frame, wheels, handlebars, seat, and pedals using Processing primitives (`ellipse`, `line`, `rect`).
* **Environment Rendering:** Draws a complete landscape featuring a blue sky, road, green lawn, and sun.

## How to Run

1. Clone or download this repository.
2. Open the project in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Ensure the **Processing core library** (`core.jar`) is added to your project dependencies/classpath.
4. Run `Main.java`.

## Requirements

* Java JDK 8 or higher
* Processing 3/4 `core.jar` library
